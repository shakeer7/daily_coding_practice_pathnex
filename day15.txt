| Task                              | Command                                           |
| --------------------------------- | ------------------------------------------------- |
| Print specific lines              | `sed -n '10,20p' file.txt`                        |
| Print lines matching text         | `sed -n '/error/p' app.log`                       |
| Replace first occurrence per line | `sed 's/old/new/' file.txt`                       |
| Replace all occurrences           | `sed 's/old/new/g' file.txt`                      |
| Replace in-place                  | `sed -i 's/old/new/g' file.txt`                   |
| Delete a line                     | `sed '5d' file.txt`                               |
| Delete lines matching text        | `sed '/error/d' app.log`                          |
| Delete blank lines                | `sed '/^$/d' file.txt`                            |
| Add text before a line            | `sed '5i\New line' file.txt`                      |
| Add text after a line             | `sed '5a\New line' file.txt`                      |
| Remove comments                   | `sed '/^#/d' config.txt`                          |
| Remove comments + blank lines     | `sed '/^#/d;/^$/d' config.txt`                    |
| Replace only a specific line      | `sed '5s/old/new/' file.txt`                      |
| Multiple replacements             | `sed -e 's/foo/bar/g' -e 's/dev/prod/g' file.txt` |
